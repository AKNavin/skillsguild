# SkillsGuild brief

An open-source community library of small, actionable AI skills grouped by business: Algo Trading, HR and Content. Users should find a task immediately, read what a skill does, and give its instructions to their AI or download a self-contained package.

The initial focus is practical Zerodha Kite workflows across research, data, stock and options signals, backtesting, regimes, execution state, risk and margins. Skills produce concrete programs and outputs. Keep each task narrow, explicit and free of repetitive background material. Source API facts and changing financial assumptions; distinguish implemented reference helpers from instructions to implement a workflow.

HR covers the employee lifecycle: company and practitioner context, writing style, role understanding, planning, hiring, onboarding, operations, pay, performance, development, engagement, relations, specialist arrangements, exits and analytics. Skills produce useful artifacts and explicit completion evidence. Reusable private context improves consistency through approved corrections; never imply model retraining or website storage of personnel data. Automate authorised administrative work while preserving accountable human employment decisions and local policy/jurisdiction requirements.

GitHub is the contribution source of truth. Reviewed, merged skill folders automatically generate cards, direct Markdown links, catalogue JSON and ZIP downloads. The public site remains a static catalogue; private broker credentials and account data never belong in it.

The interface puts business navigation, search and actions at the top, with a concise explanation of specialised skills and the open-source mission. Desktop screens show eight compact cards per row; smaller screens use fewer columns. Each card has a readable title, an accurate text-free conceptual illustration, a short description and direct Copy link and Download actions. Preserve the supplied blue SG tab logo.
