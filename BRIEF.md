# SkillsGuild

Open-source Indian strategy research. Users compare actual saved simulations, inspect exact rules and limitations, and give their AI a self-contained package to reproduce the calculation locally with authorised broker data.

The current library is the user's fifteen paper-inspired cash-equity portfolio studies through 22 October 2026. Preserve their frozen configurations and common accounting. Clearly separate the 2018–2025 selection period from the repeatedly inspected 2026 comparison. Never label these results untouched out-of-sample, unbiased, live or guaranteed.

The former HR, Content and general Algo skill catalogue has been retired. The interface uses a compact strategy table, detailed curves and trade summaries, direct downloads and AI instructions. Preserve the SG favicon. No credentials or raw broker price cache belong in this static website.

The downloadable workflow asks for broker first, then launches a local browser login helper. Broker credentials stay out of chat and normal logs. The helper performs authentication and historical-data access; it does not expose order APIs. Local process memory is not a security boundary against an unrestricted agent on the same machine.

Community changes arrive through GitHub with explicit rules, sources, reproducibility metadata and meaningful tests. Data and private accounts remain local. Source publication and research-result publication are distinct from executing a user's personal backtest.
