# Build your HR context

Create a private `hr-context.md` that other HR skills can read. This is reusable task context, not model training or a personnel database.

## Use
Read the HR professional's remit, business priorities, organisation chart, policy index and available system list. If missing, ask one compact intake covering company stage, workforce locations, HR responsibilities, recurring pain points and preferred outputs. Continue with known facts; label gaps.

1. Separate company facts, the HR professional's working preferences, approved policy and execution authority. Record source, effective date and owner for each material rule.
2. Capture HR role and seniority, supported teams, employee/contractor scope, operating calendar, time zone, systems of record, escalation contacts by role and measurable priorities.
3. Build an authority matrix: activity, allowed preparation, authorised action, approving role and evidence required. Possessing a skill or connector does not authorise a mutation.
4. Distinguish confirmed entries from inferred preferences. Ask only about inferences that affect the current output. Never infer personal traits or sensitive characteristics.
5. Save to the user's private workspace if file creation is in scope. Otherwise return the Markdown. Keep employee cases, credentials and individual compensation outside this profile.

## Deliver
Use [the context template](references/context-template.md). Include unresolved questions, version, last reviewed date and a short change log. Later corrections become proposed patches, not silent rewrites; explicit user changes supersede older preferences, while policy conflicts are flagged.

**Check:** every operational rule has a source or is marked unknown; someone can identify the responsible owner without reading old chats. Do not claim persistent memory unless the file is actually saved and supplied to later tasks.

**Try:** “Build my HR context from this handbook, org chart and description of my HRBP role. Ask only for the gaps that matter.”
