SHARE WHAT WORKS

Make the library
a little better.

A good skill is a focused, reusable workflow with clear inputs and a useful output. Contributions are reviewed before publication.

The contribution flow

  1. Fork the SkillsGuild GitHub repository once it is linked from the homepage.
  2. Add a folder under skills/algotrading/, skills/hr/ or skills/content/. Use a unique lowercase name with hyphens.
  3. Add a SKILL.md instruction file and metadata.json. You can include supporting references and assets.
  4. Run npm run validate and npm run build.
  5. Open a pull request explaining the problem, expected output and a realistic usage example. A maintainer reviews the change; merging it triggers the catalogue build.

SKILL.md

---
name: your-skill-name
description: What this skill does and when an assistant should use it.
---

# Your skill

Describe useful inputs, the workflow, output and important boundaries.

metadata.json

{
  "title": "Your skill name",
  "description": "A short, concrete description of the outcome.",
  "version": "1.0.0",
  "tags": ["workflow", "topic"],
  "author": "Your public name or GitHub handle",
  "status": "community",
  "license": "MIT"
}

Card preview image

Add preview.svg, preview.png, preview.jpg or preview.webp to the skill folder. Set image to that filename and image_alt to a plain description in metadata.json. Use a landscape image around 3:2 with a simple object illustration that closely represents what the skill does. Prefer pencil-and-watercolour artwork on a soft pastel background, with no lettering, numbers, captions or branding. The title and description explain the skill. Without an image, the website uses a text-free folder illustration.

What gets reviewed

  • The instructions do useful work and preserve the user's intent.
  • Examples are reproducible, and claims match what the skill can actually do.
  • The package has no secrets, private data, hidden files or symlinks. Each file is at most 1 MB.
  • Required tools and external dependencies are disclosed. Downloaded instructions and scripts should be inspected before use.
  • You have the right to contribute the material under the project's MIT licence.

Using a skill

Download and extract the ZIP. The folder contains the instructions, metadata and licence. Add it to your assistant's supported skill directory, or use the SKILL.md text as context. Platform support varies; this project does not promise automatic installation across every assistant.

To propose another business area, open an issue describing the use case and example skills. Publishing remains a maintainer-controlled step.
